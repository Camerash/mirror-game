# Plain traveller head study 01

This is the preserved anatomical-head trial before the user chose a simpler painted face. Its hood silhouette helped establish the next direction. The face details, separate feature pieces, and blunt hair construction are not the current target.

The source is `art_sources/traveller_head/traveller_head_study.blend`, with its builder beside it. The isolated viewer is `art_trial/head_study.tscn`; the model is `assets/studies/traveller_head.glb`. Native Blender views are in `docs/art/traveller-head-study-01/`. These are actual model renders, not generated concept art.

The head derives from the official CC0 [Human Base Meshes bundle](traveller-head-base-review.md). Rebuilding this historical trial requires the bundle at the path declared by its builder; the saved blend and GLB are self-contained. Run the builder only in a separate background Blender process with factory startup. It must not be run in an open working scene.

The next [painted-face study](traveller-painted-study-01.md) keeps this material as a comparison. Neither study replaces the gameplay character without approval.
